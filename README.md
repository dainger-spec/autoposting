# Автопостинг в Telegram с личного аккаунта

Скрипт каждый день в заданное время публикует ваши посты в чат или канал
**от имени вашего аккаунта Telegram**. Управлять постами удобно через личного бота:
создавать, менять текст и время, включать и выключать посты, отправлять их сразу.

```
   Вы ──► бот управления ──► скрипт ──► ваш аккаунт ──► ваш чат / канал
```

Бот нужен только для управления. Сообщения в чат отправляет ваш аккаунт (через
Telegram API, как обычный клиент), поэтому в чате они выглядят так, будто их
написали вы.

## Что умеет

- Посты с текстом (жирный, курсив, ссылки, цитаты и т.д.), фото, видео, GIF, файлами,
  голосовыми и альбомами. Можно просто переслать боту готовый пост из канала.
- Расписание: одно или несколько времён в день (`09:00, 18:30`) и выбор дней недели.
- Для каждого поста свой чат: можно выбрать из списка ваших групп и каналов прямо в боте.
- Кнопки «Отправить сейчас» и «Превью» (бот покажет, как будет выглядеть пост).
- Отправка без звука и отключение превью ссылок.
- Уведомления в бот: об успешной публикации и об ошибках.
- Посты хранятся в `posts.json`. Файл можно править и вручную, скрипт сам
  перечитает его без перезапуска.
- Бот отвечает только вам. Владелец аккаунта имеет доступ всегда, другим людям
  доступ можно выдать через `ADMIN_IDS`.

## Установка

Нужен **Python 3.10 или новее**.

1. **Получите API_ID и API_HASH.** Войдите на <https://my.telegram.org>, откройте
   «API development tools» и создайте приложение (название может быть любым).
2. **Создайте бота.** Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`
   и скопируйте токен.
3. **Установите зависимости:**
   ```bash
   cd autoposting
   python -m venv .venv
   # Linux / macOS:
   source .venv/bin/activate
   # Windows:
   .venv\Scripts\activate

   pip install -r requirements.txt
   ```
4. **Заполните настройки:** скопируйте `.env.example` в `.env` и впишите `API_ID`,
   `API_HASH`, `BOT_TOKEN`. Остальные параметры заполнять не обязательно.
5. **Запустите:**
   ```bash
   python main.py
   ```
   При первом запуске скрипт спросит номер телефона, код из Telegram и, если он
   включён, облачный пароль. Делается это один раз: дальше сессия хранится в `data/`.
6. Откройте своего бота в Telegram и отправьте ему `/start`.

## Как пользоваться

1. **➕ Новый пост**: пришлите текст или медиа, затем время (`09:00` или
   `09:00, 21:00`), затем выберите чат.
2. В карточке поста есть кнопки:
   - **⏸ Выключить / ▶️ Включить**: приостановить пост, не удаляя его;
   - **🚀 Отправить сейчас**: опубликовать вне расписания (бот сначала переспросит);
   - **👁 Превью**: бот пришлёт пост вам, чтобы проверить, как он выглядит;
   - **✏️ Текст / медиа**, **⏰ Время**, **📅 Дни**, **💬 Чат**: изменить настройки;
   - **🔔 / 🔕**: публиковать со звуком или без;
   - **🗑 Удалить**.
3. **ℹ️ Статус** покажет ближайшие публикации.

Команды бота: `/menu`, `/list`, `/new`, `/status`, `/cancel`, `/help`.

> Для проверки выберите чат **«Избранное»**: пост придёт в ваши «Сохранённые
> сообщения».

## Настройки (`.env`)

| Параметр | Что это |
|---|---|
| `API_ID`, `API_HASH` | данные приложения с my.telegram.org (обязательно) |
| `BOT_TOKEN` | токен бота от @BotFather (обязательно) |
| `PHONE` | номер аккаунта; если не указан, скрипт спросит его при первом запуске |
| `DEFAULT_CHAT` | чат по умолчанию: `@username`, `https://t.me/...`, `-100…` или `me` |
| `TIMEZONE` | часовой пояс расписания, по умолчанию `Europe/Moscow` |
| `ADMIN_IDS` | ID других людей, которым можно управлять ботом (через запятую) |
| `NOTIFY_ON_SUCCESS` | `true`/`false`: присылать ли уведомление о каждой публикации |
| `LATE_SEND_MINUTES` | сколько минут после назначенного времени пост ещё можно отправить, если скрипт был выключен (по умолчанию 10) |
| `POSTS_FILE` | путь к файлу с постами, по умолчанию `posts.json` |

## Посты в файле `posts.json`

Посты можно задать прямо в файле. Пример лежит в `posts.example.json`:

```json
{
  "posts": [
    {
      "text": "<b>Доброе утро!</b> ☀️\nНовости на <a href=\"https://example.com\">сайте</a>.",
      "times": ["09:00", "18:30"],
      "days": ["пн", "ср", "пт"],
      "chat": "@my_chat",
      "media": ["images/morning.jpg"],
      "silent": false,
      "enabled": true
    }
  ]
}
```

- `text`: текст с HTML-разметкой: `<b>`, `<i>`, `<u>`, `<s>`, `<code>`, `<pre>`,
  `<a href="…">`, `<blockquote>`. Перенос строки записывается как `\n`.
- `times`: список времён `ЧЧ:ММ`; можно указать и одно время: `"time": "09:00"`.
- `days`: дни недели, числами (`1` = понедельник … `7` = воскресенье) или словами
  (`"пн"`, `"вт"` …). Если не указать, пост выходит каждый день.
- `chat`: `@username`, ссылка, числовой ID или `"me"`. `null` означает
  `DEFAULT_CHAT`.
- `media`: пути к файлам (относительно папки проекта). Несколько файлов уйдут альбомом.
- `id` указывать не обязательно, скрипт проставит его сам.

Скрипт сам заметит изменения в файле. Если в JSON окажется ошибка, он сообщит о ней
в консоли и продолжит работать с прежней версией постов.

## Как работает расписание

- Каждые 15 секунд скрипт проверяет, не пора ли что-то публиковать. Каждый пост
  выходит **не больше одного раза** в назначенное время, даже после перезапуска
  (отметки хранятся в `data/state.json`).
- Если в момент публикации скрипт был выключен, но запустился в течение
  `LATE_SEND_MINUTES` минут, пост отправится с опозданием. Если позже, этот
  выпуск пропускается и пост выйдет в следующий раз по расписанию.
- При временных сбоях связи скрипт пробует ещё 2 раза. Если ничего не вышло,
  бот пришлёт сообщение с причиной ошибки.

## Запуск 24/7

Посты публикуются, только пока скрипт запущен, поэтому компьютер должен быть
включён. Удобнее всего держать скрипт на VPS. Пример сервиса systemd
(`/etc/systemd/system/autoposting.service`):

```ini
[Unit]
Description=Telegram autoposting
After=network-online.target

[Service]
WorkingDirectory=/opt/autoposting
ExecStart=/opt/autoposting/.venv/bin/python main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Перед этим один раз запустите `python main.py` вручную, чтобы войти в аккаунт.
После этого выполните `sudo systemctl enable --now autoposting`. Логи смотрите
командой `journalctl -u autoposting -f`.

## Хостинг bothost.ru

На [bothost.ru](https://bothost.ru) нет консоли, поэтому номер телефона и код там
ввести нельзя. Вход в аккаунт задаётся строкой сессии, которую один раз создают
на своём компьютере.

1. **На компьютере** установите зависимости (см. «Установка») и выполните:
   ```bash
   python login.py
   ```
   Введите номер телефона и код из Telegram. Скрипт выведет длинную строку: это и
   есть `SESSION_STRING`. Никому её не показывайте.
2. **На bothost.ru** создайте бота: укажите токен от @BotFather и загрузите код.
   Можно подключить GitHub-репозиторий или загрузить .zip-архив проекта без папок
   `.venv`, `data` и без файла `.env`.
3. Главный файл (точка входа): `main.py`.
4. В настройках бота добавьте **переменные окружения**:

   | Переменная | Значение |
   |---|---|
   | `TELEGRAM_API_ID` | ваш api_id |
   | `TELEGRAM_API_HASH` | ваш api_hash |
   | `SESSION_STRING` | строка из `python login.py` |
   | `TIMEZONE` | `Europe/Moscow` (на сервере по умолчанию UTC) |

   `BOT_TOKEN` и `DATA_DIR` платформа задаёт сама.
5. Запустите бота в панели, откройте его в Telegram и отправьте `/start`.

Посты, медиа и отметки об отправке хранятся в постоянной папке `/app/data`
(`/app/data/posts.json`), поэтому не пропадают при обновлении кода. Файл
`posts.json` можно править через файловый менеджер панели.

⚠️ Переменные окружения и постоянное хранилище на bothost входят в платные тарифы.
На бесплатном тарифе посты могут пропадать при перезапуске, так что лучше взять
хотя бы «Basic». Не запускайте скрипт одновременно дома и на хостинге, иначе
каждый пост выйдет дважды.

## Безопасность и ограничения

- ⚠️ Файл `data/user.session` даёт **полный доступ к вашему аккаунту**. Никому его
  не передавайте и не выкладывайте; `.env` тоже держите в секрете. Оба файла уже
  добавлены в `.gitignore`. Если сессия утекла, завершите её в Telegram:
  «Настройки → Устройства».
- Telegram разрешает работать с аккаунтом через API, но массовые рассылки и спам
  могут привести к ограничениям. Скрипт рассчитан на обычный постинг в свои чаты.
- Подпись к медиа без Premium ограничена 1024 символами, текст сообщения 4096
  символами. В альбоме может быть до 10 файлов.
- Стикеры, опросы и геолокации в качестве поста не поддерживаются.
